# MitoMapa canario · REA editable 4.8.2

22/10/2026

Se sustituyen las imágenes de los dos selectores de islas y los ocho premios
nativos por las vasijas y la caracola aprobadas, con la misma colocación y tamaño.
Las ocho pintaderas decorativas de la portada, el mapa, los cuentos, las escenas,
las dieciséis pistas de audio, los datos y las reglas de las actividades se conservan.
El pasaporte sigue siendo una lista de revisión manual independiente de la web.

Se actualizan conjuntamente el modelo editable, el índice y las páginas exportadas,
incluidos los datos que utiliza eXeLearning para mostrar los premios. Se incorporan
las fuentes de las imágenes en el apartado correspondiente. El archivo mantiene
34 páginas, 118 iDevices y 42 juegos nativos, compatible con eXeLearning 4.0.5.

Las imágenes nuevas se añaden con nombres propios: no se sobrescriben los medios
anteriores ni la fuente inmutable 4.7.1. La web continúa como un enlace adicional,
sin aplicación embebida ni sincronización de resultados con el ELPX.
