# MitoMapa canario · web 4.8.6

22/10/2026

El banco de tarjetas de «Las piezas y sus islas» muestra únicamente las
imágenes: se oculta el texto visible «Pieza N» situado bajo cada una. El nombre
y el estado de cada tarjeta se conservan para lectores de pantalla. Las imágenes
y los controles con arrastre, toque, clic y teclado siguen disponibles.

Este ajuste visual solo afecta a la web. No cambia los requisitos del juego,
el pasaporte ni el diploma. El REA editable 4.8.4 conserva exactamente sus bytes
y su huella; la entrega completa 4.8.4 y los paquetes anteriores permanecen
intactos. La publicación 4.8.6 ofrece nuevos paquetes de fuentes y documentación
con una copia del mismo ELPX 4.8.4.
