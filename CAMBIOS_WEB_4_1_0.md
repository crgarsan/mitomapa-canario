# MitoMapa web 4.1.0 — 05/10/2026

La exploración de las islas y la lectura incorporan nuevas actividades:

- Mapa navegable con ocho botones y expediciones de cinco pistas aleatorias,
  ayuda visible, respuestas inmediatas y posibilidad de continuar a otro cuento.
- Cuatro acontecimientos de cada recreación literaria para ordenar con botones,
  comprobar, consultar una pista y utilizar un orden de apoyo.
- Comparación de dos relatos con preguntas para conversar, orientaciones por
  etapa y notas locales que se pueden recuperar por pareja de islas y descargar.
- Puzle disponible en un apartado desplegable y retorno desde los cuentos al
  mapa y la expedición de pistas.

Las actividades son opcionales. Se mantienen los requisitos de las pintaderas,
la revisión docente de los itinerarios, el diploma y las claves del progreso
anterior. Las secuencias y las comparaciones se incluyen en el seguimiento
exportado; los archivos anteriores siguen siendo compatibles.

Los controles usan botones, etiquetas y mensajes de estado, funcionan sin
arrastre y adaptan su disposición a pantallas pequeñas. No hay límites de tiempo.
Los acontecimientos proceden de los cuentos del recurso y se presentan como
recreaciones literarias, no como evidencia histórica.

El ZIP editable corresponde a la web 4.1.0. El REA nativo y sus dos selecciones
conservan la versión 4.0.2 y el formato de eXeLearning 4.0.5; las nuevas
interacciones están en la web editable. Se mantienen las descargas anteriores.

La publicación se realiza desde GitHub Actions al actualizar `main`. El
resultado del despliegue se comprueba en la dirección pública, no mediante un
campo estático de estado en `VERSION.json`.
