Guide to using and reusing MitoMapa

The editable project and the website

ELPX. An editable eXeLearning project with stories, activities, images and recordings. The last page links to the website as an optional extra.

Website. The standalone website has its own games, settings and local progress tracking. Instructions that refer to website controls apply to the website.

Authors: Jesica Fortes Regalado, Gloria Elsa González Martín and Cristian García Santana.

Published web version: 4.10.0 · Editable open educational resource 4.8.9, English edition. Prepared for eXeLearning 4.0.5.

Start with a story

Choose any island for a session, and explore further when it suits the group. The practical teacher guide explains how to prepare the group, plan a flexible session, support reading and creative work and choose games that serve your aim. In Teacher, the Activity guide opens first. Settings and progress provides tools to organise and save work on this device.

Mediateca and direct download

In Resources, use the first card to open the MitoMapa record in the Canary Islands Government Mediateca and find its options for use and download. The Mediateca record is for the Spanish edition. Use the direct downloads on this page for the English eXeLearning project and sharing package.

The ELPX button downloads the project file. If an in-app browser cannot save it, open the link in an external browser or download this edition’s ZIP package. The package contains the same editable resource, version 4.8.9.

Educational use and aims

MitoMapa offers supported reading, primary and secondary tasks and support that teachers can adapt. Find the islands where stories are set, understand their narrative elements, distinguish tradition from fictional recreation, compare sources and create a response. Each route offers guidance for the selected learning stage. Teachers choose tasks and support for their group. Learners can follow different sequences.

Exploring, matching, sequencing and comparing on the website

The website offers five optional activities involving exploration, matching names and pieces, sequencing and comparing stories. The names game offers a chance to check historical names against sources. The pieces game matches passport recreations to islands. Sequencing and comparing use the stories written for this resource. These activities are separate from the piece, diploma and route review requirements.

  • Interactive map. Open an island or start a five-clue expedition. Ask for help or try again as needed, with no time limit. The pieces and names stay on the islands on small screens. Scroll the map with touch, the keyboard or the west and east buttons.
  • Island names. Match seven historical names and the ‘No documented name’ card to the map. Drag them, select and place them with touch, a click or the keyboard, or use the accessible form. The antique-style chart is a modern design based on the original map’s geography. The evidence varies for each name. Check the sources to find out what is known about each name’s origin and age. Read the sources and cautions. The game gives no pieces or grades. You can complete the agreed route without playing it.
  • Match the pieces to their islands. Match the seven vessels and the shell for La Graciosa to the islands they represent in MitoMapa. Drag or select them with a click, touch, the keyboard or a drop-down list. Use the reference and clues, and try again as needed. The associations are part of this recreation. Consult the sources for archaeological evidence. The game gives no scores or awards and is separate from the passport and route tasks.
  • Put the story in order use the ‘Move up’ and ‘Move down’ buttons to order four events. Check the sequence and use a clue or the example order if you need help. Use the activity to practise your understanding of the story.
  • Two stories, one conversation choose two islands. Compare similarities, differences, decisions and consequences. Learners can add notes to discuss or review with a teacher.

In early years, read with support and retell events aloud. In primary education, explain the order and compare the stories. In secondary education, explain causes and consequences and distinguish fiction from historical evidence. The instructions reflect the learning stage you select.

The browser stores sequences and notes on this device. They are included in the file from Teacher → Settings and progress → Save a copy. You can also download the comparison. Loading a progress file from before these activities were added starts with blank answers. A file containing activity data restores it. Resetting progress also clears these answers. Map clues belong to the current expedition. The pieces game resets when you reload and its answers are excluded from the saved progress file.

These activities are on the website. The ELPX 4.8.9 is a standalone native eXeLearning resource. Its final section links to the website as an optional extra, which requires an internet connection.

Supporting work and resuming an activity on the website

The passport counts pieces that meet the selected stage’s requirements. Changing stages keeps the history. If the new stage requires a true or false challenge that remains incomplete, the piece counts again after that challenge is completed. The diploma opens when all eight pieces meet the current requirements. Common comprehension and true or false challenges carry across stages with the same requirements.

Pieces record the automatic challenges. In early years and the first primary cycle, learners complete comprehension. In other stages, they also complete true or false. In Teacher, record agreed tasks and mark the route as reviewed after discussing the evidence with learners. This mark is stored locally for the selected stage. It records the teacher’s review without certifying a signature or assigning a grade. Changing a task clears that task’s review. Choose the route’s islands in Teacher → Settings and progress. A route through two islands is complete when those two islands are reviewed. Route completion is separate from the eight-piece collection and gives no points or grades. Review any changed work again with the teacher. Switching stages preserves the marks for other stages.

Adapting the resource without coding

Download the English edition of the editable resource, version 4.8.9. Open it in eXeLearning 4.0.5 or a compatible installation and save a copy before editing. It contains 34 pages, 118 iDevices, 42 native games and 16 audio tracks. Edit the stories, activities and guidance in eXeLearning. The source sections group references and the teacher guidance expands on request. The native passport is filled in by hand. The final page includes an optional link to the standalone website, which is distributed separately. Editing the project leaves the website as it is. Before classroom use, test opening, navigation and export in your installation.

Planning an activity with the teacher guide

Teacher opens on the Activity guide. It covers the aim, preparation, a suggested session, support for reading and creative work, adaptations for other groups and optional games. Open the full teacher guide to print or share. Open the separate Settings and progress tab to organise and save work locally. Explore the islands in any order using the interactive pieces. A session can focus on the islands you choose.

Finding your way around the website

From Home, start exploring or resume the last island and open the learning stage and reading settings. Islands contains the map and clues. Games includes the puzzle, story comparison and final challenge. Resources contains materials, credits, sources and feedback. On an island, Story, Challenges and Workshop show one section at a time. Use the top navigation or browser buttons to move around and keep your session’s answers and drafts.

Source code on GitHub

Find the website code and project materials in the MitoMapa repository on GitHub. The public repository lets you consult and download the source files. When adapting a copy of the code, retain the authors, credits and licence and describe your changes. Use the ELPX download link in this guide for the editable resource.

Sharing and keeping a copy

Keep the download and save a copy of the ELPX before adapting it in eXeLearning. It contains editable chapters, images, teacher guidance and local recordings. The website is separate, and learner answers and data are stored outside the project. The final website link and the external sources require internet access. The website can be used without an account, with progress saved separately in each browser. To keep it when changing devices or addresses, use Teacher → Settings and progress → Save a copy. Follow the GitHub link for source code.

Workbook and assigned tasks on the website

In Teacher, choose Vocabulary, Research and Create for each island and stage. The counter shows only assigned sections. By default, early years and the first primary cycle have no Workbook sections, the second cycle has Vocabulary and the third cycle and Secondary have all three. Enable or disable sections without changing stage. ‘No tasks’ means that the Workbook has no sections assigned for that island and stage.

Primary and Secondary drafts are saved while learners write. ‘Mark as ready’ records that the response is ready to share. Revising it clears that status and the manual review for routes that use the response. The browser also saves vocabulary and research answers. Learners can record a source and a fact they checked, and then discuss the quality of the comparison with their teacher.

For work shared aloud, on paper or through another tool, choose ‘Oral or away from the website’. Review the evidence before marking work outside the website as reviewed. In Secondary, teachers can adjust the length of a written response while using the review checklist and evidence. Learners may use support. Download the draft and progress to keep a copy if you change devices or local storage fails.

Native eXeLearning progress report

The GobCan edition 4.8.9 has 34 pages, 118 iDevices and 42 native games that can be tracked. Teachers assign tasks for the agreed route. The four-session, two-island example uses selected games. Review open tasks and the native passport by hand. The website has its own local progress record, separate from the native report and ELPX SCORM score.

Adjust the iDevices that you are not assigning and test the package in Moodle before use. Selecting games for the report alone does not change the SCORM completion settings.

To select games by a shared identifier and number of activities, follow the official eXeLearning 4.0.5 Progress Report manual.

Optional feedback about the resource

Use ‘Share feedback’ after one or more routes. The five questions cover ease of use, instructions, visual clarity, perceived learning and satisfaction. Two open questions ask about preferences and difficulties. Review ‘Unable to rate’ answers separately. Feedback does not affect pieces or grades. Perceived learning is one kind of feedback and does not establish educational impact.

Download selected ratings, written comments or both. Written comments can be shared without ratings. The download is created locally without collecting names or sending responses. To share a Google Forms feedback form with the whole group, publish the form and enter its response link in configuracion.js before deploying the website. A public response link was unavailable in the files reviewed. The Teacher option sets it for the current browser. The ELPX and website collect feedback separately. Check linked services before use. If you gather observations from both resources, leave out personal data and record which resource was used.

If a source link is unavailable

External sources depend on their original services. If a link requires verification or is unavailable, keep the bibliographic reference and use another suitable source agreed with your teacher or a permitted accessible copy. The story sources on the website distinguish tradition, documented information and fiction. In the ELPX, expandable sections group the references. Consult and evaluate the source itself.

Saving progress on the website

Progress stays in the browser at the resource’s web address. Names, answers, drawings and progress expire after 15 days; returning does not renew the period. Cleanup runs while the website is open or when you return and keeps general settings. Existing undated work receives 15 days from the first visit with this update. Importing or resetting starts a new period; downloaded copies are not deleted. Before you change device, browser or domain, use Teacher → Settings and progress → Save a copy. On the new device or address, choose ‘Restore a copy’. If you see a storage notice, download a copy before closing. Progress files can contain the optional name or written work. Share them with the intended recipient. Using the same browser and address keeps the previous progress available where local storage is enabled and the data remains saved.

What the pieces represent

The passport features seven pottery recreations and a shell for La Graciosa. Sources on the islands’ pottery provided visual references for the vessels. The shell is a modern symbol of La Graciosa’s connection with the sea. The pintaderas are decorative. Check the sources for the passport pieces and distinguish the recreations from the material evidence studied by archaeologists.

Accessibility checks and their scope

The website provides alternatives to dragging, text alongside audio, visible keyboard focus and activities without a time limit. Checks of web version 4.4.0 covered navigation, keyboard controls, old links, storage, printing and reflow at 320 and 390 pixels in Chromium. axe-core 4.10.3 found no automated issues against WCAG 2 A/AA, 2.1 AA and 2.2 AA in the ten views and steps checked at 390 pixels, including expanded Resource sections. These checks covered the stated views and conditions. Screen reader tests, tests on physical mobile devices and a complete manual accessibility evaluation are still pending. Educational impact needs classroom evidence.

Privacy and hosting

Progress and downloadable feedback stay in the browser. If the optional external form is enabled, the school should review the service, the information requested and its suitability for children before sharing the link. For institutional publication, agree on a stable domain and maintenance plan. If the address changes, learners can save their progress from Teacher at the old address and restore it at the new one.

What can an illustration tell us about the past?

These AI-generated illustrations accompany original stories. Clothing, objects, faces, buildings, actions and landscapes are depicted for the stories. Use historical and archaeological sources to check what is known about them.

To learn about the past, use different sources and compare their evidence. Many accounts of names and beliefs come from texts written after the conquest and reflect the authors’ perspectives. Archaeology studies material remains, and oral traditions preserve stories and their variants. Use those sources to check details you notice in an illustration.

  • Written account: Who wrote it, when and for what purpose?
  • Archaeological evidence: What object or site was studied? What conclusions can it support?
  • Oral tradition: Who told the story, where, and which versions do we know?
  • Fiction in MitoMapa: characters, dialogue and scenes created for reading and storytelling.

Look closely at the image · optional activity

Primary: Look at an illustration and name two things you can see. Choose one detail that needs checking. With your teacher’s help, consult a source and finish these sentences. “In the picture I see…” “The source explains…” “We still do not know…”

Secondary: Choose a detail and ask a question. Compare a written source with archaeological evidence or a relevant specialist study. Record the author, date, link and what each source supports. Distinguish fact, interpretation and fiction. Look at who acts, who stays in the background and whose ages or roles are missing. Are there stereotypes about gender, age or appearance? Explain a change you would make. Say what remains uncertain.

Review with your teacher: Identify your sources, explain what they support, acknowledge what remains uncertain and describe your proposed improvement. Give your answer aloud or in your notebook. Earning a piece is independent of this optional activity.

Island names and how to read their sources

The routes use the islands’ current names. Some sources record other names whose spelling, use and interpretation vary. The authors report consulting specialists in the pre-Hispanic Canary Islands about the game selection. The linked bibliography is a separate source of evidence. Use the sources to see the differing levels of support for each name. The game presents selected spellings and the limits of the evidence. The note on sources explains which forms were selected and the limits of the evidence.

Historical names and what the sources support

TenerifeChineche / Achinech / Achineche are variants recorded in historical writing.
Gran CanariaCanaria is a historical name of uncertain origin. Reliable records identifying Tamarán as the Indigenous name are lacking.
La PalmaBenahoare appears in historical sources.
La GomeraThe authors supplied Gomara after consulting specialists. The linked bibliography gives Gomera. The same documentary support and an etymology for Gomara remain unestablished.
El HierroEsero and Eceró are the forms selected for the game. The linked bibliography records Esero. The same level of support for Eceró remains unestablished. The name bimbapes for the island’s Indigenous people is preserved in El Hierro’s oral tradition.
FuerteventuraLe Canarien records the name Erbania.
LanzaroteLe Canarien records Tyterogaka. Its spelling varies across transcriptions.
La Graciosa‘No documented name’ is a category in the activity. No documented Indigenous name for the island has been established here. A lack of permanent settlement leaves open the possibility of visits or occasional use.

Notes on the evidence: Studies of the oral tradition of El Hierro support the use of bimbapes here. Wider scholarly agreement and any institutional recommendation remain unconfirmed. The cross episode in Mafasca is evidence about some versions of the legend. Its earliest origins remain uncertain. Compare written accounts with archaeological evidence for a fuller picture.
