# REA GobCan 4.5.0 · 14/10/2026

Se alinean las ocho listas de creación con las consignas de Primaria y Secundaria, admitiendo modalidades orales, gráficas y escénicas y el estado «No procede». Las diez listas cualitativas no suman puntos.

Se revisan las alternativas de las ocho escenas vigentes, sus créditos y la trazabilidad de fuentes por cuento. Se mantienen las ilustraciones y narraciones actuales.

Se mejora el acceso mediante teclado, el foco, la asociación entre controles y enunciados y la comunicación textual de resultados en los componentes que lo requieren. El Explorador local incluye las correcciones de la web y el contacto de sugerencias.

La estructura y las identidades de los componentes se preservan. VERSION.json y la validación de entrega recogen la estructura, huellas y comprobaciones efectivas.
